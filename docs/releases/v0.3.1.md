# Ting 0.3.1

## Fixes

- Reduced the gap between the amber top rule and the leader-key entry row in
  selecta when **Show panel title** is off, to match launcha. Spacing with the
  title shown is unchanged.
- Hid the technical “App index depth limit reached.” notice in launcha. Other
  app-index errors and file-search errors remain visible.

## Upgrade and install

Requires **macOS 14 or later**. The universal ZIP supports **Apple Silicon and Intel**.

To upgrade an installed copy, choose **Check for Updates…** in the menu-bar
menu. Your settings, leader and bindings are kept.

For a new or manual installation, download `Ting-0.3.1-universal.zip` from
[Releases](https://github.com/bobuk-io/ting/releases/latest) and unzip it. Quit
any running copy of Ting, move `Ting.app` to `/Applications` (replace the old
copy for a manual upgrade), and open it. Ting lives in the menu bar and has no
Dock icon. On first launch, choose a leader key; there is no default leader.

The official release is signed with Developer ID, notarized by Apple, and
includes a stapled notarization ticket. Verify the archive with
`SHA256SUMS.txt` if desired. Ting needs no Accessibility or Input Monitoring
permission.

# Ting 0.2.0

**Ting** is a leader-key launcher for macOS. Press your leader key, then one key
or a short sequence to open an app or a link.

## Highlights

- First public release.
- **Any key can be the leader**, alone or with modifiers: `Home`, `F13`,
  `⌥⇧⌘F` and so on. A modifier on its own cannot be a leader.
- **Automatic updates** with Sparkle from this repository's releases. Turn
  automatic checks off or check now in Settings → General, or choose
  **Check for Updates…** in the menu-bar menu.
- Nested groups of bindings; letters, digits, `Space`, `Return` and F-keys in
  sequences; `Esc` closes the menu and `Delete` goes back.
- Works with any keyboard layout, including Russian and Ukrainian. The menu shows
  the current layout's letter next to the Latin one.
- Settings with a **Sequences** table: record keys, finish with **Done**; missing
  groups are created and empty groups removed automatically.
- One JSON configuration file at `~/.config/ting/config.json`, reloaded when it
  changes. Light and dark themes, dark by default.
- New app icon: an amber sound-system pad.

## Install

Requires **macOS 14 or later**. The universal ZIP supports **Apple Silicon and Intel**.

Download `Ting-0.2.0-universal.zip`, unzip it, move `Ting.app` to Applications
and open it. Ting lives in the menu bar; press the key you want as your leader.

The app is signed with Developer ID, notarized by Apple, and includes a stapled
notarization ticket. Verify the archive with `SHA256SUMS.txt` if desired.

## Notes

- Ting opens apps and URLs. Shell commands are not supported.
- Ting needs no Accessibility or Input Monitoring permission.

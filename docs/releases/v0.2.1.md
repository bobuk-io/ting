# Ting 0.2.1

## Changes

- **New menu-bar icon**: a tuning fork, the source of the "ting" sound. It is a
  template image, so it follows the light and dark menu bar.

## Install

Requires **macOS 14 or later**. The universal ZIP supports **Apple Silicon and Intel**.

If Ting 0.2.0 is installed, choose **Check for Updates…** in the menu-bar menu.
Otherwise download `Ting-0.2.1-universal.zip`, unzip it, move `Ting.app` to
Applications and open it.

The app is signed with Developer ID, notarized by Apple, and includes a stapled
notarization ticket. Verify the archive with `SHA256SUMS.txt` if desired.
